Run it yourself

A practice run is free. An AI stand-in plays Flashpoint and invents the answers, so no email is sent and no credit is spent.

node agent/agent.mjs "Figure out the best event to put on for our club next spring." --practice

A real run emails the people on your list through the Flashpoint MCP and pays for each step from a budget you set. Add --hands-off and nobody has to stay at the keyboard: the code checks each survey before it is sent.

node agent/agent.mjs "Figure out the best event to put on for our club next spring." --cap 9

How to set it up is in the agent's README. The whole run on this page is written out in its log.
